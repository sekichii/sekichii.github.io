# My Portfolio
A fast, lightweight personal portfolio built with **Rust**, **Yew** and **Sass**, and compiled to **WebAssembly** using **Trunk**.

## Tech Stack
* **Framework:** [Yew](https://yew.rs/)
* **Bundler:** [Trunk](https://trunk-rs.github.io/trunk/)
* **Styling:** [Sass/SCSS](https://sass-lang.com/)
